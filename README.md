# SunbYte Software Handbook

A central collection of software engineering standards, guidelines, and resources for the **SunbYte Software Team**.

This repository aims to promote consistent development practices, maintainable code, and effective collaboration across SunbYte's software projects. This is a living repo, and anyone is welcome to make changes at any time. If doing so, please open a branch so it can be merged after review.

## Contents

### Git & Collaboration

- [Commit Guidelines](git/commit-conventions.md) - Conventions for writing clear and consistent Git commit messages.

*Additional guidelines will be added as the team develops.*

## Contributing

This handbook is a collaborative resource maintained by the SunbYte Software Team.

Team members are encouraged to suggest improvements, contribute new guidelines, and update existing documentation as our practices evolve.

To propose a change, open an issue or submit a pull request.

## Guiding Principles

- **Clarity over cleverness:** Write code that others can easily understand and maintain.
- **Consistency:** Follow shared conventions across projects.
- **Simplicity:** Prefer straightforward solutions over unnecessary complexity.
- **Collaboration:** Share knowledge, review constructively, and document important decisions.
- **Continuous improvement:** Treat our standards as evolving practices rather than fixed rules.
